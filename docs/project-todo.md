# PlayCock 작업 이력 및 To-Do

이 문서는 PlayCock 프로젝트를 GitHub에 업로드하기 전, 현재까지 진행된 작업과 앞으로 진행할 작업을 신규 참여자가 빠르게 이해할 수 있도록 정리한 문서입니다.

## 1. 현재 프로젝트 상태

PlayCock은 배드민턴 모임 운영을 위한 관리자 중심 웹 애플리케이션입니다. 현재는 로컬 개발 환경에서 동작하는 단계이며, 프론트엔드와 백엔드가 분리되어 있습니다.

- 프론트엔드: React + Vite
- 백엔드: Spring Boot
- 로컬 DB: H2 file DB
- DB 마이그레이션: Flyway
- 빌드 도구: Gradle Wrapper, npm/Vite

현재 주요 관리자 화면은 아래 라우트로 구성되어 있습니다.

- `/admin/live`: Live Dashboard
- `/admin/sessions`: 세션 관리
- `/admin/history`: 운동 이력
- `/admin/analytics`: 월간 통계
- `/admin/finance`: 운영비 관리
